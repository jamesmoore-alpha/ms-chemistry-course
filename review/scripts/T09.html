Chemical symbols: one element or two?

MAT-053 · Chemical symbols — Read a chemical symbol correctly, including applying the capitalisation rule to tell one element from two.

Script
SayScreen

So what does the small letter mean?[the o and the O glow; question mark]
It means the short name is one name, not two.[Co underlined as one unit; C and O underlined as two]

This short name is called the element's chemical symbol.[chip: CHEMICAL SYMBOL]

So every capital letter starts a new symbol.[CO: two rings, one on each capital]
Co has one capital letter, so Co names one element: cobalt.[Co; 1 capital; tick; ONE ELEMENT: cobalt]
But CO has two capital letters, so CO names two elements: carbon and oxygen.[CO; 2 capitals; cross; TWO ELEMENTS: carbon, oxygen]
And HF has two capital letters too, so HF names two elements.[HF; 2 capitals; cross; TWO ELEMENTS: hydrogen, fluorine]
But Hg has one capital letter, so Hg names one element.[Hg; 1 capital; tick; ONE ELEMENT: mercury]
So, here's what we've seen. Count the capital letters, and you count the elements.[the rule slide: the five symbols with their rings and ticks; nothing else printed]
So on the shelf, Co is one element, and CO is two symbols written together.[the two bottles; the rings on the capitals]
Okay, now your turn.[closing screen: one line — "Count the capital letters, and you count the elements."]

The periodic table: every element on one chart

MAT-054 · The periodic table organises all known elements — State what the periodic table is and what it organises.

Script
SayScreen
Scientists know 118 elements, and the number of protons decides which element an atom is.[118 in large type; an atom with its nucleus counted]
So each element has its own count of protons, from 1 to 118.[cards with 1, 2, 3 … 118]
Imagine 118 cards, one for each element, tipped out onto a desk.[the cards tumble into a heap]
How would you lay them out so you could find any element fast?[question mark over the heap]
You lay them out in order of their proton count: 1, then 2, then 3, and so on.[cards slide into a row: 1, 2 … ]
The cards run along a row, and a new row starts underneath when the row is full.[row 1 ends at 2; row 2 fills 3 to 10; rows build to 118]
This chart of every known element, one box each, is called the periodic table.[the finished table; chip: PERIODIC TABLE]
Look at carbon's box: the small 6 at the top is there because every carbon atom has 6 protons.[carbon's box enlarged; the 6 glows]
On the table, this number of protons is called the element's atomic number.[chip: ATOMIC NUMBER = number of protons]
The makers ended each row so that elements that behave alike landed in one column.[row 1's two boxes; one column lights up top to bottom]
So, the periodic table is a chart of every known element, one box per element.[the rule slide: the table with carbon's box ringed; chips PERIODIC TABLE, ATOMIC NUMBER; nothing else printed]
The boxes run in order of atomic number, and the atomic number is the number of protons.[the path along the rows; carbon's 6 glows]
So the cards, laid out in order row by row, make the periodic table.[the heap becomes the table]
Okay, now your turn.[closing screen: one line — “The periodic table is a chart of every known element, one box per element.”]

“Okay, now your turn.” — the attached question

  1. A the elements' names, A to Z
  2. B how common each element is
  3. C the number of protons
Answer

Key: C — the number of protons

Each box carries its element's count of protons.
The boxes run 1, 2, 3 and on to 118.
So the table runs in order of the number of protons.

Feedback per option

  • A The boxes are not sorted by name; they run 1, 2, 3 by proton count.
  • B How common an element is plays no part; the boxes run by proton count.
  • C The boxes run 1, 2, 3 and on to 118: in order of the number of protons, the atomic number.
